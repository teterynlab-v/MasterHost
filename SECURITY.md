# Security reporting

Do not open a public issue containing an exploitable vulnerability, credentials, database dumps or private game data. When GitHub private vulnerability reporting is enabled for this repository, use its Security → Report a vulnerability flow. Until that facility is enabled, contact the repository maintainer privately through an established channel; there is no public security inbox configured yet.

Include the affected release, steps to reproduce, expected authorization boundary and sanitized impact. Avoid accessing other people's games to demonstrate a problem.

MasterHost is currently a development preview. The hosted demo's shared access password is not an individual account system. Campaign GM, participant and Realm administrator authorization remain separate; do not share administrator credentials with invited players.

Supported fixes currently target the latest development source. No long-term support or vulnerability-response SLA is promised.
