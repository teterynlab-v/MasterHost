# Run and join a game

## Game Master

1. Choose **Create a game** and select one compatible asset in every guided category.
2. Review dependencies and licenses, compile, then return to the game library.
3. Choose **Run game**, name the Campaign and create the room.
4. Copy the invitation link. It contains the short-lived PIN and opens the correct Session.
5. Wait for a player and choose **Start session**.
6. Use **Table** for scenes and maps; **Checks & actions** for dice and rules; **Encounter** for turns; **Party** for Actors and rewards; **Journal** for history and completion.

Use `.mhgame` to share a complete authored game. Use a PostgreSQL backup to protect active Campaign and Session history.

## Player

1. Open the invitation link, or choose **Join a game** and enter the six-digit code.
2. Enter a display name, select or create a compatible Character, then mark ready.
3. Required rolls appear as the strongest action. Phone navigation jumps to Character, abilities, map, party and journal.
4. Reopen the same browser to reconnect. Choose **Join another game** to leave.

Application navigation and bundled official universe content support English, Russian, Spanish, Japanese, Simplified Chinese and Korean. User-authored text stays in its original language. Human editorial review of the translations is still pending; see [localization status](CONTENT_LOCALIZATION_STATUS.md).
