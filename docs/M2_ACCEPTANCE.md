# First Playable Mechanic Acceptance

1. Complete M1 Character Lobby flow.
2. GM starts Session LIVE.
3. GM selects player and Perception (Fantasy) or Intrusion (Cyberpunk).
4. GM sets difficulty and sends Check.
5. Player receives pending Check.
6. Player clicks ROLL.
7. Server generates dice result.
8. Server applies Character modifier.
9. Resolution is persisted.
10. GM event log contains CheckRequested, DiceRolled, CheckResolved.
11. Refresh clients.
12. Event history and resolved check remain persisted.
