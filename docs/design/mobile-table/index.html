Предложение дизайнера · на согласование

Один экран — одна задача

Карта занимает доступное пространство. Персонаж, сцены и журнал открываются вкладками, а не лежат длинной колонкой под ней.

Мастер уже в мире

Игроки подключаются по мере готовности. Кнопка группы открывает список участников, приглашение и управление. Ожидание всех не блокирует стол.

Игрок: карта + персонаж + кубик

Проверка появляется над навигацией на любой вкладке. Кубик остаётся кубиком. Нажатие открывает результат; выбор цели и действия — в панели.

Нулевой ресурс — локальное состояние

В карточке выдержка равна нулю: здоровье, фокус и инвентарь остаются видны со своими значениями. Эффекты и последствия определяются выбранным набором правил.

Проверка перед применением

  • Экран 360–430 px без горизонтальной прокрутки.
  • Основные области нажатия не меньше 48 px.
  • Нижние панели учитывают клавиатуру и safe area.
  • Нет опасных действий по одному случайному нажатию.
  • При потере связи действия блокируются; текущая карта и персонаж остаются на экране. Обновление вкладки возвращает в ту же сессию, без нового мира.
  • Мастерские секреты не появляются в интерфейсе игрока.
  • Это веб-интерфейс с мобильными паттернами, не отдельное приложение.
