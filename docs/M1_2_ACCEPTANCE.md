# M1.2 Character Lobby Acceptance

1. GM creates World, Campaign, Session.
2. Player opens `#join`, enters PIN and nickname.
3. Player sees Character Builder defined by active World Pack.
4. Fantasy shows Name + Archetype; Cyberpunk shows Handle + Role.
5. Player creates Character.
6. Character is attached to SessionParticipant.
7. Player toggles Ready.
8. Refresh and join another session using same browser identity.
9. Previously created compatible Character appears in Saved Characters.
10. Select it without recreating it.
11. GM starts Session; Player sees LIVE.
