# Licensing

- MasterHost source code is released under the MIT License in [`LICENSE`](../LICENSE).
- Bundled official World Pack text and original artwork declare `CC-BY-4.0` attribution in each Pack manifest.
- Game assets declare license, source, attribution and immutable checksum in the asset registry.
- `node scripts/build-release.mjs VERSION` writes the installed dependency inventory to `THIRD_PARTY_LICENSES.json` in every release archive.

The current dependency set uses MIT, ISC, Apache-2.0, BSD-3-Clause, 0BSD, CC-BY-4.0 and Unlicense. Inventory is release evidence, not a substitute for legal review of external contributions.
